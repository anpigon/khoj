# 개인 정보 보호

Khoj를 사용하여 개인 데이터를 색인화하는 경우, 색인화하고 싶은 민감하고 사적인 정보가 거의 확실히 있을 것입니다.

Khoj는 개인 AI로 설계되었으므로, 우리의 핵심 원칙 중 하나는 가능한 한 개인 정보 보호에 친화적으로 만드는 것입니다. 그렇기 때문에, 항상 자신의 하드웨어에서 Khoj를 실행하고 데이터를 장치 외부로 공유하지 않도록 선택할 수 있습니다. 머신에서 직접 임베딩을 생성한 다음 오프라인 채팅 클라이언트를 사용하여 데이터가 머신을 떠나지 않도록 할 수 있습니다. [자체 호스팅](./setup.mdx) 지침은 여기에서 찾을 수 있습니다.

자체 호스팅이든 클라우드에서든 Khoj를 사용하는 경우 고려해야 할 사항은 다음과 같습니다.
1. Khoj와 채팅할 때 관련 색인화된 데이터 중 일부가 컨텍스트로 포함될 수 있습니다. 이는 OpenAI 모델 중 하나를 사용하는 경우 OpenAI로 전송될 수 있음을 의미합니다.
1. 우리는 완전히 익명화된 사용량 원격 측정 데이터를 수집하여 [PostHog](https://posthog.com/)로 보냅니다. 여기에는 고유 채팅 요청, 고유 검색 요청, 데이터 색인화에 대한 고유 요청과 같은 데이터가 포함됩니다. 사용량 데이터는 사람들이 Khoj를 어떻게 사용하는지 이해하고 기능 우선 순위를 정하는 데 도움이 되도록 수집됩니다.
    - IP 주소를 기록하거나 개인 데이터를 PostHog에 업로드하지 않습니다.
    - 원격 측정 집계 코드는 [여기](https://github.com/khoj-ai/khoj/blob/master/src/khoj/routers/helpers.py#L71)에서, 원격 측정 서버는 [여기](https://github.com/khoj-ai/khoj/blob/master/src/telemetry/telemetry.py)에서 확인할 수 있습니다.
    - 자체 호스팅하는 경우, [이 지침](/miscellaneous/telemetry)에 따라 원격 측정을 거부할 수 있습니다.

자체 호스팅이 모든 사람에게 적합한 것은 아니므로, [클라우드 서비스](https://app.khoj.dev/login)를 사용하더라도 Khoj가 개인 정보 보호에 친화적이도록 조치를 취했습니다. Khoj 클라우드를 사용할 때 고려해야 할 사항은 다음과 같습니다.
1. 임베딩은 [Huggingface와 함께 AWS에서 호스팅되는](https://huggingface.co/inference-endpoints/dedicated) 자체 전용 엔드포인트 내의 오픈 소스 모델에 의해 생성됩니다. Huggingface 추론 엔드포인트에는 영구적인 메모리가 없습니다(상태 비저장).
1. 임베딩 및 관련 원시 텍스트는 개인 AWS 클라우드의 보안 Postgres DB에 저장됩니다. 데이터는 고유 사용자 ID로 분할됩니다. 파일 동기화를 개선하고 Khoj와 채팅할 때 컨텍스트를 제공하기 위해 파일의 원시 텍스트를 저장합니다.
1. Google을 통한 단일 로그인 옵션을 사용하는 경우, 이름, 프로필 사진 링크 및 이메일 주소만 받습니다.

전체 개인 정보 보호 정책은 [여기](https://khoj.dev/privacy-policy)에서 확인할 수 있습니다.

:::tip[정보]
귀하의 데이터는 귀하의 것입니다. 우리는 귀하의 데이터를 판매하거나 모델 훈련에 사용하지 않습니다. Khoj는 폐쇄형 상업용 개인 AI에 대한 지속 가능한 오픈 소스 대안입니다. 우리는 빠른 돈을 벌기 위해 귀하의 데이터를 판매하는 데 관심이 없습니다.
:::

우리는 Khoj를 개인 AI 및 클라우드 서비스로서 정말 강력하게 만들면서도, 신뢰할 수 있고 개인 정보 보호 중심적으로 만드는 방법에 대한 많은 아이디어를 가지고 있습니다. 이것이 귀하에게 중요하고 우리가 이를 구축하는 데 도움을 주고 싶다면 [연락](mailto:team@khoj.dev) 주십시오.
