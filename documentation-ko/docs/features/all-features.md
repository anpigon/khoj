# 개요

Khoj는 다양한 데이터 소스 및 인터페이스를 통한 검색 및 채팅을 포함한 다양한 기능을 지원합니다.

#### [검색](/features/search)
  - **로컬**: 개인 데이터는 로컬에 유지됩니다. [자체 호스팅](/get-started/setup)할 때 모든 검색 및 색인 작업은 사용자 머신에서 수행됩니다.
  - **증분**: 빠르고 입력과 동시에 검색되는 경험을 위한 증분 검색

#### [채팅](/features/chat)
  - **더 빠른 답변**: 검색보다 더 빠르고 부드럽게 답변을 찾습니다. 답변을 찾기 위해 노트를 수동으로 스캔할 필요가 없습니다.
  - **반복적인 발견**: 노트를 반복적으로 탐색하고 (재)발견합니다.
  - **보조적인 창의성**: 답변 검색과 콘텐츠 생성을 원활하게 결합합니다.
  - **온라인 또는 오프라인 작동**: 온라인 또는 오프라인 AI 채팅 모델을 사용하여 채팅합니다.

#### 일반
  - **클라우드 또는 자체 호스팅**: 언제 어디서든 Khoj를 사용하려면 [클라우드](https://app.khoj.dev/login)를 사용하거나, 개인 정보 보호를 위해 [자체 호스팅](/get-started/setup)합니다.
  - **자연어**: 트랜스포머 기반 ML 모델을 사용한 고급 자연어 이해
  - **플러그인 가능**: 모듈식 아키텍처로 새로운 데이터 소스, 프론트엔드 및 ML 모델을 쉽게 연결할 수 있습니다.
  - **다중 소스**: Org-mode, Markdown, PDF, 일반 텍스트 파일, Github 리포지토리 및 Notion 페이지를 색인화합니다.
  - **다중 인터페이스**: 웹 브라우저, Emacs, Obsidian, 데스크톱 앱 또는 Whatsapp에서도 상호 작용합니다.

### 지원되는 인터페이스
Khoj는 [데스크톱 앱](/clients/desktop), [Emacs 패키지](/clients/emacs), [Obsidian 플러그인](/clients/obsidian), [웹 앱](/clients/web) 및 [Whatsapp AI](https://khoj.dev/whatsapp)로 제공됩니다.

![](/img/khoj_clients.svg ':size=400px')

### 지원되는 데이터 소스
Khoj는 Word, PDF, org-mode, Markdown, 일반 텍스트 파일 및 [Notion 페이지](/data-sources/notion_integration)를 이해할 수 있습니다.
