# 자동화

[자동화](https://app.khoj.dev/automations)는 Khoj가 사용자를 대신하여 반복적인 작업을 예약하는 강력한 기능입니다. 자동화를 사용하면 예약된 시간과 빈도로 쿼리를 자동으로 실행할 수 있습니다. Khoj는 연구 결과를 이메일로 보내드립니다.
Khoj에게 맞춤 뉴스레터를 만들거나, 뉴스를 요약하거나, 세계 이벤트를 알려달라고 요청할 수 있습니다.

Khoj는 일정을 위해 현지 시간대를 사용합니다. [자동화 페이지](https://app.khoj.dev/automations)에서 자동화를 구성, 공유 및 삭제할 수 있습니다.

:::info[자체 호스팅]
자체 호스팅 사용자는 Khoj가 자동화 이메일을 보내도록 Resend 및 [인증](/advanced/authentication) 설정을 해야 합니다.
:::
